# CAMELS-FI scripts
This repository contains all the code that was used for creating CAMELS-FI. 
Data publication is under preparation.
CAMELS-FI is a large sample hydrometeorological dataset, for Finland, containing:
- daily discharge data of up to 63 years (1961-2023) for 320 gauges,
- catchments for those gauges
- daily meteorology for 10 different variables, averaged for the catchments (1961-2023)
- 80 different biogeophysical and societal attributes averaged for the catchments
    - Landcover is also provided as annual timeseries, interpolated from all Corine Land Covers produced for Finland
 
Data is available from [Zenodo](https://doi.org/10.5281/zenodo.15853357)
